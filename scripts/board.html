What this means

Every commit an agent makes gets an Entire-Checkpoint trailer pointing at the AI session that wrote it. The session's transcript is stored in a private sessions repo. Open a commit to see which functions, types and sections that session changed, from entire graph checkpoint.

How agents use them

Before editing, each agent runs entire brain brief "<task>" to get the team's decisions and rules, then entire graph query to find the code and entire graph impact to see what a change would break.

After deciding, it posts a DECISION on the channel and records it with entire brain remember, so every other agent's next brief includes it.

Runs on your machine. It reads GitHub with your gh login, Entire with your entire login and history with git. It never reads session transcripts or prompts.
